# Wrathnilla 2 Tweaker

Tweak your Wrathnilla experience without messing around in config files.

**Use at your own risk**

## Startup

### Simple

Copy the .exe file to your Wrathnilla server directory and launch. It should load the config file automatically.

### Custom location

On the first start you will be prompted to locate the config folder of your Wrathnilla server.

## Editing values

### Sections and values

The various settings are grouped in logical, hopefully self explaining sections. All values have a help box next to them that show default and suggested values.

### Rudegoblins Suggestions

These suggestions are completely optional. They reflect how I set up the game to be more Vanilla like.

## Automatic backups

With each save, an automatic backup is created. The backup is saved in the same directory as the config file with a timestamp in the filename.
